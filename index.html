HEOR Scenario Lab: which assumptions actually drive the cost-effectiveness result?

Jane Natividad  ·  jane-natividad.github.io  ·  View on GitHub

A transparent cohort-level model comparing a hypothetical new intervention with a hypothetical comparator. Change prices, other healthcare costs, quality of life, time horizon, discounting and the willingness-to-pay threshold. The lab then calculates incremental cost, incremental QALYs, the ICER (only where it means something) and incremental net monetary benefit, and shows which assumptions move the result most.
1 · Assumptions (all illustrative)

Perspective: healthcare payer. Included costs: treatment acquisition plus other direct healthcare costs, entered as annual amounts. Outcomes: QALYs = annual utility × years, discounted. Currency: generic "$". Every number is illustrative, not drawn from any real product, trial or HTA submission.

2 · Results
Cost-effectiveness plane: incremental QALYs (x) vs incremental cost (y). The dashed line is the willingness-to-pay threshold. Points below it have positive net monetary benefit.
3 · Scenarios

Each preset starts from the base case and changes one assumption, so the scenarios stay comparable. Custom scenarios save whatever is currently set.

Saved scenarios appear here. The base case is saved automatically.
4 · One-way sensitivity analysis & thresholds

Each parameter is moved alone to its low and high value; everything else stays at the current setting. Bars show the effect on incremental net monetary benefit. The threshold column shows the value at which INMB would equal 0 at the current willingness to pay, which is where the modelled result flips.

5 · Probabilistic sensitivity analysis

Draws every uncertain input from an explicit distribution 2,000 times (seeded, so reproducible). Costs: gamma. Utilities: beta. Spreads are illustrative, not estimated from data.

Model documentation

Model structure

A deterministic, two-strategy, cohort-level model with annual cycles. For each strategy s and year t = 0 … H−1: Total cost_s = Σ_t (treatment_s(t) + other_s) / (1 + r_c)^t treatment_s(t) = annual price while t < treatment duration, else 0 Total QALYs_s = Σ_t utility_s / (1 + r_o)^t ΔC = Cost_new − Cost_comp ΔE = QALYs_new − QALYs_comp ICER = ΔC / ΔE (reported only when ΔE ≠ 0, with its quadrant) INMB = WTP × ΔE − ΔC Discounting runs from the start of each year (year 0 undiscounted). Cost and outcome discount rates are set separately.

Perspective, horizon and costs

Healthcare payer perspective. Horizon of 1–30 years, as set. Annual treatment and other direct healthcare costs. Productivity and out-of-pocket costs are excluded.

QALY assumptions

Each strategy has one average utility per year, applied to the whole cohort for the full horizon. There's no mortality or disease-state structure, so both arms are assumed to survive the full horizon. That simplification is acceptable for a teaching model and not for a real submission.

Dominance and the ICER

Dominant: cheaper and more effective, so no ICER is needed. Dominated: dearer and less effective. North-east: dearer and more effective, so the ICER is compared with WTP. South-west: cheaper and less effective. The ICER is then savings per QALY lost, and the decision rule reverses (the new option is preferred only if the ICER is above WTP). When ΔE = 0 no ICER is shown. INMB is reported in every case and is the primary result. With more than two strategies, extended dominance would also need checking. This version only compares two.

Sensitivity analysis methods

One-way: each parameter is moved over a low–high range you can edit (default ±20%), and the threshold value for INMB = 0 is found by bisection. Probabilistic: annual costs are drawn from Gamma(mean, SE) and utilities from Beta(mean, SE) using method-of-moments, with SE as a share of the mean (costs) or an absolute value (utilities). Draws are independent. That's a simplifying assumption, since real inputs are often correlated.

Data provenance

All inputs and distributions are illustrative and invented for demonstration. None comes from a real product, trial or HTA dossier.

Validation requirements

For real use you'd need: inputs sourced from trials, real-world evidence and published utilities, with documented SEs; a disease model with survival and states; face validity reviewed by clinicians; verification of every equation, including a parallel spreadsheet rebuild; and cross-validation against published models.

Limitations

No survival or disease states, no half-cycle correction, independent PSA draws, and a single cohort average with no subgroups. A positive INMB here means "favourable under these assumptions at this threshold". It is not a reimbursement recommendation.
